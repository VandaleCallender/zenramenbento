# zenramenbento

Website for Zen Ramen & Bento, 51 W Main St, Dahlonega, GA 30533.

A single static page (`index.html`) plus images in `img/`. There is no build step: open `index.html` in a browser, or deploy the folder to any static host (Vercel, Netlify, GitHub Pages).

The menu data, hours and phone number are near the bottom of `index.html` (`MENU`, `TOPS`, `SAKE`, `HOURS`).
